# GULZA — Pembuat Video Lirik Bergerak

GULZA membuat video lirik dan subtitle bergerak di browser, lalu mengekspornya sebagai MP4.

Di versi fork ini, file SRT dapat diimpor langsung tanpa diubah menjadi LRC terlebih dahulu.

## Mulai cepat

1. Impor file SRT atau LRC, atau ketik lirik satu frasa per baris.
2. Jika perlu, impor audio dan atur waktu tiap baris.
3. Tekan tombol untuk membuat variasi gaya dan susunan.
4. Lihat pratinjau, lalu ekspor MP4.

Impor SRT mempertahankan waktu mulai, waktu selesai, dan jeda antar-subtitle. Penanda waktunya dapat diedit di bidang lirik.

## Bahasa dan penyuntingan

Menu bahasa antarmuka ada di bagian atas aplikasi. Alamat utama menggunakan bahasa Korea secara bawaan.

Pengaturan **Bahasa lirik** berbeda dari bahasa antarmuka. Pengaturan ini memilih font dan pemenggalan teks; nilai bawaannya adalah deteksi otomatis.

Tersedia juga pengaturan waktu manual, pilihan rasio layar, ekspor PNG, penyimpanan proyek JSON, dan ekspor JSON untuk After Effects.
