# GULZA — 免費動態歌詞與字幕影片製作工具

**[使用繁體中文網站](https://ruruoni1.github.io/gulza/zh-hant/)** · [韓文原文](README.md) · [原始 JIZURA](https://github.com/852wa/JIZURA)

**其他語言：** [한국어](README.md) · [日本語](README.ja.md) · [English](README.en.md) · [简体中文](README.zh-Hans.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md)

GULZA 是免費的瀏覽器工具，可用歌詞和字幕製作動態影片並儲存為 MP4。

名稱取自韓語「글자」（文字）。

本專案以 [JIZURA](https://github.com/852wa/JIZURA) 的 860 個表現元件與 27 種風格為基礎。

這個分支可以直接匯入 SRT 字幕檔，不必先轉換成 LRC。

**目前版本：v0.14.7** · 不需要安裝或註冊，即可使用[網站](https://ruruoni1.github.io/gulza/zh-hant/)。主網址預設為韓文介面，可在畫面上方切換語言。

## 這個分支新增的功能

- **直接匯入 SRT：** 直接開啟 `.srt` 檔案製作字幕影片；沒有字幕的片段也會保留。
- **韓文字幕檔案支援：** 可讀取 UTF-8、UTF-16 及韓文 Windows 編碼的 SRT/LRC，檔案上限為 2 MB。
- **匯出 LRC：** 將各字幕的開始時間存成 LRC。若要保留結束時間，請儲存包含 SRT 的專案。
- **切換介面語言：** 預設為韓文，也可選擇日文、英文、繁體與簡體中文、印尼文和越南文。
- **GULZA 檔名：** 未輸入標題時，使用 `gulza.mp4`、`gulza.project.json` 等預設檔名。

SRT 時間標記會以 `[SRT:00:00:01.000-->00:00:02.300]字幕` 的形式顯示於歌詞欄。

修改標記即可調整字幕時間。

## 主要特點

- **自動配置：** 一鍵式 `R` 使用按鍵重新建立風格、情緒、動作、配色方案和剪切構圖。如果您更改種子，影片將會有所不同。
- **編輯時間：** 您可以偵測音源的節拍並設定剪切，或在播放過程中直接點擊以指定行和剪切的開始時間。
- **輸出設定：** 選擇 16:9、9:16、4:3、3:4、1:1、4:5、21:9 寬高比、720p~4K 解析度、24/30/60fps。
- **影片和圖片：** 您可以匯出 MP4、PNG 序列、透明 PNG 和前景/背景分離的 PNG。您也可以在綠幕和黑色背景之間進行選擇。
- **儲存項目：** 您可以將編輯儲存為 JSON 並重新打開，甚至可以匯出 After Effects 的設定 JSON。

## 入門

1. [古爾扎網站](https://ruruoni1.github.io/gulza/zh-hant/)打開 。
2. **載入SRT/LRC**用 選擇字幕文件，或直接在歌詞輸入欄中逐行寫入。
3. 如果有聲源，則載入它。即使沒有音訊來源，您也可以建立帶有字幕的視訊。
4. **自動建立**點擊並檢查預覽。我喜歡的是 **上一頁/下一頁**您可以再次選擇它。
5. 設定好螢幕比例、解析度、幀率後， **匯出MP4**按 。

### 使用環境

MP4 匯出需要瀏覽器中的 WebCodecs 支援。推薦使用 Chrome 和 Edge。

可用的編解碼器會因您的瀏覽器和作業系統而異。即使您無法建立 MP4，您仍然可以預覽和匯出 PNG 序列。

您也可以在智慧型手機上進行編輯。 PC 更適合長視訊或高解析度輸出。

所需的字體是從 Google Fonts 加載的。離線時，裝置上的字體可能會回退。

## 自動建立和微調

螢幕的 **簡單/進階**更改 中的編輯模式。

在簡單模式下 **自動建立**按一次可重新選擇以下全部內容。

- 標題和正文中使用的樣式、背景顏色和字體
- 情緒：小故障、寒冷、流行、圖形、社論、情感，綜合混合。如果你開啟恐怖導演，恐怖也會被納入候選範圍。
- 動作的強度、故障和裝飾的數量以及要使用的表現力部件。
- 剪切配置和種子

**上一頁/下一頁**您可以在使用 建立的記錄之間來回切換。

**只需更改這部分即可**保持當前設計並僅選擇以下其中一項：風格、配色方案、氛圍和構圖。

歌詞、聲音來源、時間、輸出設定和鎖定行都是自動建立的，不會變更。

### 手機螢幕

當螢幕較窄或使用觸控操作時 **移動的** 模式可用。

即使滾動時，自動產生的按鈕和預覽也是可見的。透過僅展開您需要的行來編輯行列表。

儲存、開啟、重置都集中在選單中。移動模式下的第一個輸出解析度是720p。

### 更改配色方案

**進階 → 樣式 → 強調色/偏移色**在 **隨機配色方案**按 重新選擇兩種顏色。

您可以從現成的組合或色輪中創建新的組合。還可以調整顏色的亮度，以便根據背景亮度來讀取文字。

您也可以自己指定顏色。如果清除指定的顏色，它將返回樣式的預設顏色。

## 瀏覽器編輯詳細說明

### 歌詞和字幕符號

通常，一行歌詞就是一個短語。

空白行會產生短暫的間隙。

| 輸入範例 | 意義 |
|---|---|
| `새벽의 색을/기억하고 있어` | `/`將切口分開。 |
| `*투명*` | 強調這個詞。 |
| `마지막 문장!` | 在行尾添加閃光和擺動。 |
| `가사\|작은 메모` | 新增小文字以供評論。 |
| `[01:23.45]가사` | 應用 LRC 開始時間。 |
| `[간주 8]` | 它只顯示了8秒的背景和裝飾，沒有任何歌詞。如果沒有數字，則為 4 秒。 |
| `# 메모` | 這將被視為作品註釋，不會包含在影片中。 |

**載入SRT/LRC**如果使用 開啟文件，目前歌詞將會變更。更改之前將打開一個確認視窗。

即使在打電話之後 **恢復**您可以使用 恢復之前的狀態。

SRT 維護開始和結束時間。 LRC 只能包含開始時間。

### 聲源及時序

- 當您載入聲源時，它會偵測 BPM 和節拍，並將剪切邊界調整為更接近節拍。載入的音樂將保留在同一瀏覽器中，並且可以在您重新開啟頁面時恢復。
- **與選項卡同步：** 當每一行開始時 `Space`按 。如果您按錯了按鈕 `Backspace`我 **恢復一**使用 。
- **再次從中間開始：** 按下線路清單中的同步按鈕。
- **選項卡輔助功能：** 您可以將播放速度降低至 0.75 倍或 0.5 倍，或開啟倒數計時。保存時間是歌曲的原始時間。
- **剪切時間：** 當一條線路有多個剪切時，切換時 `Tab`按 。
- 您可以直接以數字形式輸入行列表的開始時間，也可以透過拖曳時間軸的行邊框來調整它。您也可以放大/縮小時間軸並移動播放位置。
- 歌詞和時間變更 **恢復** 或者 `Ctrl+Z`您可以使用 取消。

### 分別編輯線條和剪切

您可以按下行列表中的鉛筆按鈕或雙擊歌詞來編輯該行。

每條線的切割次數可以設定為自動或 1 到 6。您也可以用骰子再次繪製該線。

打開後，鎖會保持其線條的組成和配色方案。 **隨機播放**重新拉動整個配置而不鎖定它。

**主題**如果選擇文字影片、動態、日式、恐怖、流行、民謠之一，自動產生方向將會縮小。

在進階模式下，您可以變更每個剪輯的佈局、外觀、維護、退出、裝飾、文字效果、背景、相機和過渡。

即使在自動建立後，分類鎖定和表示值鎖定仍會保留，並保存在專案檔案中。

下次去玩 **重複**依下列順序變更：全部→行→剪切→無重複。

重複範圍顯示在時間線上。

### 風格、方向、字體

27 種樣式是結合了顏色組合、字體和紋理的設定。

有櫻花、深海、日落、報紙、紙張、合成器和恐怖風格。即使在一個影片中，每次剪輯的背景也可能會發生變化。

需要時載入字體。您的 PC 上安裝的字型名稱 `.ttf`·`.otf` 您也可以將其變更為文件。

**進階 → 方向**調整運動、故障、顏色錯位、裝飾、切割密度、紋理和框架保持。

即使你隱藏了裝飾性的數字和時間，歌詞中寫的數字本身也會保留下來。

**進階 → 技術**您可以單獨開啟和關閉 10 類表情元件。它還提供名稱搜尋和完整的開/關/反轉。

**團結感**打開後，單獨的部分和重複的歌詞使用相似的佈局和動作。在需要強調的線條上放置強而有力的方向。

**字元對齊**調整字體大小、間距和裝飾。這兩個選項都可以關閉。

**空中心（用於字元）**確保中心空間以合成其他影像。

歌詞在橫屏上左右放置，在垂直屏幕上上下或左右放置。

預覽中的虛線顯示將留空且不會包含在輸出中的範圍。

### 輸出格式及範圍

| 形式 | 使用 |
|---|---|
| MP4 | 完成影片。如果您有聲源，則可以將其包括在內。 |
| PNG 序列 ZIP | 在其他編輯器中組裝逐幀影像時使用。 |
| 透明PNG ZIP | 用於在沒有背景的情況下組合文字和簡報。 |
| 單獨的前景和背景 PNG ZIP | `front/`和 `back/` 將一幀的正面和背面元素分別保存在資料夾中。 |
| LRC | 這是一個歌詞文件，記錄了​​每一行的開始時間。 |
| After Effects 的 JSON | 用於將目前時序和配置資訊傳輸到 GULZA AE 面板。 |

**出口範圍**如果選擇第一行或最後一行，則僅列印所選行。在檔案名稱中 `_L03-05`行號加如下。

在Chrome·Edge中，您可以將大影片直接錄製到要儲存的檔案中。如果GPU編碼失敗，請嘗試其他方法。

如果您的瀏覽器無法儲存 AAC 音頻，則可能會同時儲存一個單獨的 WAV 檔案。

**清晰的歌詞**清除每句歌詞和台詞的計時、指定和輸出範圍。此動作是可逆的。

**重置**刪除已儲存的音樂、設定甚至工作歷史記錄。確認後即執行且不可撤銷。

單獨下載的項目 JSON 檔案不會被刪除。

### 幀速率和運動

從 24/30/60fps 中選擇輸出幀速率。幀速率和運動紋理是單獨的設定。

- **2 幀保持：** 每秒 12 張圖片的移動會產生一種斷開的感覺。
- **3幀保持：** 每秒 8 次射擊營造出更冰凍的感覺。
- **全部的：** 它以每個選定的輸出 fps 移動，以獲得最流暢的體驗。

60fps 和 4K 需要更長的時間才能輸出。

### 綠幕、黑色背景和透明PNG

將歌詞放在另一個影片之上 **匯出 → 背景**在綠幕、黑色背景或純背景之間進行選擇。

綠屏是綠色的 `#00FF00`，黑色背景為黑色 `#000000`使用 。設定會反映在預覽和輸出中。

在檔案名稱中 `_greenback` 或者 `_blackback`這是附上的。

使用色度鍵去除綠屏，使用螢幕合成或亮度鍵去除黑色背景。

如果選擇透明PNG，則可以在不刪除背景的情況下進行合成。在前景和背景分離的ZIP中， `front/`投擲 `back/` 將其放在上面。

Flash 和螢幕效果可以套用在兩層中，因此請檢查合成結果。

## After Effects 面板

提供以 GULZA 名稱建置的 ScriptUI 與 CEP 兩種面板。

選單、產生的合成、診斷報告檔名和 CEP 擴充 ID 都使用 GULZA 名稱。

瀏覽器版的 **匯出至 AE** 會將每個剪輯的開始與結束時間寫入 JSON。

ScriptUI 面板會把這些時間套用至 AE 圖層的起點與終點。

| 類型 | 檔案 | 用途 |
|---|---|---|
| ScriptUI | [`GULZA_AE.jsx`](GULZA_AE.jsx) | 在 AE 中以歌詞建立合成，或讀取瀏覽器版的配置 JSON。 |
| CEP | [`GULZA_CEP.zip`](GULZA_CEP.zip) | 在 AE 面板中使用韓文瀏覽器編輯介面。 |

### 安裝 ScriptUI

1. 下載 `GULZA_AE.jsx`。
2. 將檔案放進 AE 安裝資料夾的 `Scripts/ScriptUI Panels`。
3. 重新啟動 AE，從 **視窗 → GULZA_AE.jsx** 開啟。

選擇歌詞、風格、畫面大小與效果後建立合成。

開始時間可自動計算，或使用所選音訊圖層與合成的標記。

也可讀取瀏覽器版儲存的 **AE 用 JSON**，以相同時間與配置建立合成。

產生的歌詞仍是可編輯的文字圖層。

### 安裝 CEP

1. 下載並解壓縮 `GULZA_CEP.zip`。
2. 依作業系統執行 `install_win.bat` 或 `install_mac.command`。
3. 重新啟動 AE，從 **視窗 → 擴充功能 → GULZA** 開啟。

CEP 適用於 AE 2022 或更新版本。擴充 ID（`com.ruruoni1.gulza`）與原始 JIZURA 面板不同。

安裝程式會將面板複製到使用者 CEP 擴充資料夾，並啟用未簽署 CEP 面板的執行設定。

詳見 [CEP 安裝說明](cep/dist/README_CEP.md)。

兩種面板均提供輕量產生、進度與停止控制，以及診斷報告。

本次發佈使用的電腦未安裝 After Effects，因此尚未確認面板在 AE 中的實際運作。

## 開發與發行

瀏覽器版本是從儲存庫根建構的，如下所示：

```sh
python build.py
```

`src/`, `app/`, `vendor/`從根源上 `index.html`班級 `sitemap.xml`生成 .

GitHub 頁面 `main` 發布分支的儲存庫根。 [預設位址](https://ruruoni1.github.io/gulza/zh-hant/)是韓國的螢幕。

還在每個語言資料夾中建立日語、英語、中文（繁體、簡體）、印尼語和越南語的 HTML。

原始 After Effects 特定的建置工具也在儲存庫中。

```sh
node tools/export_ae_data.js
python build_ae.py
python build_cep.py
```

瀏覽器版本是 [`VERSION`](VERSION)，變化歷史為 [`CHANGELOG.md`](CHANGELOG.md)把它寫下來。

新增表達式部分 [`docs/EXPRESSION_PACKS.md`](docs/EXPRESSION_PACKS.md)請參考。

如果您重新建立了 AE·CEP 輸出，則必須在 After Effects 中單獨檢查它。
