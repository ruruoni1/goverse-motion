# GULZA — 動態歌詞影片製作工具

GULZA 可在瀏覽器中製作動態歌詞與字幕影片，並匯出 MP4。

這個分支可以直接匯入 SRT 字幕檔，不必先轉換成 LRC。

**[開啟繁體中文版](https://ruruoni1.github.io/gulza/zh-hant/)** · [儲存庫首頁（韓文）](README.md) · [原始 JIZURA](https://github.com/852wa/JIZURA)

其他語言：[한국어](README.ko.md) · [日本語](README.ja.md) · [English](README.en.md) · [简体中文](README.zh-Hans.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md)

## 快速開始

1. 匯入 SRT 或 LRC，或逐行輸入歌詞。
2. 視需要匯入音訊並調整時間。
3. 產生新的樣式與畫面配置。
4. 預覽後匯出 MP4。

匯入 SRT 時，會保留字幕的開始時間、結束時間及字幕間的空白。也可以在歌詞欄修改時間標記。

## 介面與歌詞語言

介面語言選單位於網站上方。主網址預設顯示韓文介面。

**歌詞語言**是另一項設定，用來選擇字型與文字分段方式；預設為自動偵測。

也支援手動調整時間、畫面比例、PNG 匯出、專案 JSON，以及 After Effects 用 JSON。

GULZA 以 [JIZURA](https://github.com/852wa/JIZURA) 為基礎。原始碼採用 [MIT 授權條款](LICENSE)。
