# GULZA — 無料の歌詞・字幕モーション動画メーカー

**[日本語のウェブサイトを使う](https://ruruoni1.github.io/gulza/ja/)** · [韓国語の原文](README.md) · [元の JIZURA](https://github.com/852wa/JIZURA)

**ほかの言語:** [한국어](README.md) · [English](README.en.md) · [繁體中文](README.zh-Hant.md) · [简体中文](README.zh-Hans.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md)

GULZA は、歌詞や字幕からモーション動画を作り、MP4 に保存できる無料のブラウザーツールです。

名前は韓国語の「글자（文字）」に由来します。

[JIZURA](https://github.com/852wa/JIZURA) の表現パーツ 860 個とスタイル 27 種類を基にしています。

このフォークでは、SRT 字幕ファイルを LRC に変換せず、そのまま読み込めます。

**現在のバージョン: v0.14.9** · インストールや登録は不要です。[ウェブサイト](https://ruruoni1.github.io/gulza/ja/)をすぐに使えます。ルートの URL は韓国語で開き、画面上部で表示言語を変更できます。

## このフォークで追加した機能

- **SRT の直接読み込み:** `.srt` ファイルをそのまま開いて字幕動画を作れます。字幕のない区間も動画に反映します。
- **韓国語の字幕ファイル:** UTF-8、UTF-16、韓国語 Windows エンコーディングの SRT/LRC を読み込めます。上限は 2 MB です。
- **LRC の書き出し:** 各字幕の開始時刻を LRC に保存します。終了時刻も残すには、SRT を含むプロジェクトを保存してください。
- **表示言語の切り替え:** 韓国語を既定として、日本語、英語、繁体字・簡体字中国語、インドネシア語、ベトナム語を選べます。
- **GULZA のファイル名:** タイトルがない場合は `gulza.mp4`、`gulza.project.json` などの名前で保存します。

SRT の時刻は歌詞欄に `[SRT:00:00:01.000-->00:00:02.300]字幕` のように表示されます。

時刻の表記を編集すると、字幕のタイミングも変わります。

## 主な機能

- **自動構成：** ボタン一度 `R` キーでスタイル、雰囲気、動き、配色、カット構成を再作成します。シードを変えると別の映像になります。
- **タイミング編集：** 音源の拍子を感知してカットを合わせたり、再生しながら直接タップして行とカットの開始時刻を指定できます。
- **出力設定：** 16:9、9:16、4:3、3:4、1:1、4:5、21:9 アスペクト比と720p～4K解像度、24/30/60fpsを選択します。
- **ビデオと画像：** MP4、PNGシーケンス、透明PNG、前景・後景分離PNGをエクスポートできます。グリーンスクリーンと黒の背景も選択できます。
- **プロジェクトの保存:** 編集内容をJSONとして保存して再度開くことができ、After Effects用の構成JSONもエクスポートできます。

## 始める

1. [GULZAサイト](https://ruruoni1.github.io/gulza/ja/)を開きます。
2. **SRT/LRCの読み込み**で字幕ファイルを選択するか、歌詞フィールドに1行ずつ直接書きます。
3. 音源があれば呼び出されます。音源がなくても字幕映像は作れます。
4. **自動作成**を押してプレビューを確認します。お気に入りの中 **前/次**でもう一度選択できます。
5. アスペクト比・解像度・フレームレートを決めた後 **MP4 エクスポート**を押します。

### 使用環境

MP4 エクスポートにはブラウザの WebCodecs サポートが必要です。ChromeとEdgeをお勧めします。

利用可能なコーデックは、ブラウザとオペレーティングシステムによって異なります。MP4を作成できなくても、プレビューとPNGシーケンスのエクスポートは利用できます。

スマートフォンでも編集できます。長い映像や高解像度出力にはPCがより適しています。

必要なフォントはGoogle Fontsから読み込まれます。オフラインでは、デバイス上のフォントに置き換えることができます。

## 自動生成と詳細調整

画面の **シンプル/アドバンス**で編集モードを切り替えます。

シンプルモードで **自動作成**を押すと、次の項目を一度に再度選択します。

- スタイルと背景色、タイトル・本文に書くフォント
- 雰囲気：グリッチ、落ち着き、ポップ、グラフィック、エディトリアル、感性、フルブレンド。ホラー演出をオンにするとホラーも候補に入ります。
- 動きの強さ、グリッチと装飾の量、使用する表現部品
- カット構成とシード

**前/次**で作成した中の記録を行くことができます。

**この部分のみ変更**では、現在の中を維持したままスタイル、配色、雰囲気、構成のうちの1つだけを再び抜きます。

歌詞・音源・タイミング・出力設定とロックされた行は自動生成に変わりません。

### 自動生成に使用する表現範囲

チェック項目で自動生成・シャッフル・行別再抽選の候補を制限できます。

直接選択した表現は、この制限に関係なく使用できます。

| アイテム | 最初の状態 | 仕組み |
|---|---|---|
| 追加の演出も使用 | オフ | オンにすると、初期公開版の356部品と12スタイルに追加された表現とスタイル、フォントも候補に含まれます。 |
| 和風演出も使用 | 点灯 | チョロン・ショウジ・扇子・桜・伝統柄など日本風表現を候補に含みます。 |
| タイポグラフィ部品の使用 | 点灯 | 線、数字、字間、文字組版で表現する文字映像用部品50個を使用します。 |
| キネティック部品の使用 | 点灯 | 単語が移動し、積み重ねたり交差する51個の部品を使用します。 |
| ホラー演出も使用 | オフ | ホラー部品52個と関連スタイル3個を使用し、自動生成雰囲気にホラーを追加します。 |

表現リストでは追加分・日本風・タイポグラフィ・キネティック・ホラー部品にそれぞれ表示がつきます。

現在の設定で自動選択されていない項目はぼやけて見えます。

### モバイル画面

画面が狭いときやタッチで操作するとき **モバイル** モードを使用できます。

自動生成ボタンとプレビューはスクロール中にも表示されます。行リストは必要な行だけを展開して編集します。

保存・開く・初期化はメニューに集めました。モバイルモードの最初の出力解像度は720pです。

### 配色を変える

**高級→スタイル→強調色・オフセット色**から **ランダム配色**を押すと、2色を再選びます。

準備された組み合わせまたはカラーリングから新しい組み合わせを作成できます。背景の明るさに合わせて、文字が読み取られるように色の明るさも調整します。

色を直接指定することもできます。直接指定した色をオフにすると、スタイルの基本色に戻ります。

## ブラウザ編集詳細ガイド

### 歌詞と字幕表記

通常歌詞の一行が一フレーズです。

空行は短い間隔を作成します。

| 入力例 | 意味 |
|---|---|
| `새벽의 색을/기억하고 있어` | `/`でカットを分けます。 |
| `*투명*` | その単語を強調します。 |
| `마지막 문장!` | 行の最後にフラッシュと揺れを置きます。 |
| `가사\|작은 메모` | 注釈用の小文字を付け加えます。 |
| `[01:23.45]가사` | LRC開始時刻を適用します。 |
| `[간주 8]` | 8秒間は歌詞なしで背景と装飾のみを表示します。数字がない場合は4秒です。 |
| `# 메모` | 作業用注釈で処理して映像には入れません。 |

**SRT/LRCの読み込み**でファイルを開くと、現在の歌詞が変わります。変更する前に確認ウィンドウが開きます。

呼んだ後も **元に戻す**で直前の状態を回復できます。

SRTは開始・終了時刻を維持します。LRCは開始時刻のみを保持できます。

### 音源とタイミング

- 音源を読み込むと、BPMと拍子を検出してカット境界を拍子に近づけます。読み込んだソースは同じブラウザに保存され、ページを再度開くと復元できます。
- **タブで同期：** 各行が始まるとき `Space`を押します。間違って押すと `Backspace`私 **1つ戻す**を使用します。
- **途中から再開：** 行リストの同期ボタンを押します。
- **タブ補助機能：** 再生速度を0.75倍・0.5倍に下げたり、カウントダウンをオンにすることができます。保存時間はソングの元の時間です。
- **カットタイミング：** 1行に複数のカットがある場合 `Tab`を押します。
- 行リストの開始時刻を数値で直接入力するか、タイムラインの行境界をドラッグして調整できます。タイムラインの拡大・縮小や再生位置の移動も可能です。
- 歌詞・タイミング変更は **元に戻す** または `Ctrl+Z`でキャンセルできます。

### 行とカットを別々に編集する

行リストで鉛筆ボタンを押すか、歌詞をダブルクリックすると、その行だけを編集できます。

行ごとにカット数を自動または1～6個で指定できます。サイコロでその行だけを再び引くこともできます。

ロックをオンにすると、その行の構成と配色が維持されます。 **シャッフル**は、ロックされていない完全な構成を再び取り出します。

**テーマ**で文字映像、キネティック、日本風、ホラー、ポップ、バラードのいずれかを選ぶと自動生成方向が絞り込まれます。

高級モードでは、レイアウト・登場・維持・退場・装飾・文字効果・背景・カメラ・切替をカットごとに変更できます。

分類別ロックと演出値ロックは、自動生成後も保持され、プロジェクトファイルにも保存されます。

再生の横に **繰り返し**は全体→行→カット→繰り返しなし順に変わります。

繰り返し範囲はタイムラインに表示されます。

### スタイル、演出、フォント

27スタイルは配色・書体・質感を結んだ設定です。

さくら、深海、夕日、新聞、紙、シンセ系列やホラー用スタイルなどがあります。1つの画像でもカットごとに背景が異なる場合があります。

フォントは必要に応じて呼び出されます。PCにインストールされているフォント名または `.ttf`·`.otf` ファイルに置き換えることもできます。

**上級→演出**で動き、グリッチ、色のずれ、装飾、カット密度、テクスチャ、フレームホールドを調整します。

装飾用の数字や視覚を隠しても、歌詞自体に書かれた数字は保持されます。

**高度→技法**では、10の分類の表現部品を個別にオン/オフできます。名前検索と全体のオン・オフ・反転も提供します。

**統一感**をオンにすると、区切られた部分と繰り返し歌詞に似たレイアウトと動きを使用します。強調する行には強い演出を配置します。

**文字の並べ替え**は文字サイズ・間隔・装飾を調整します。どちらのオプションもオフにできます。

**中空(キャラクター用)**は中央に他の映像を合成する空間を確保します。

横画面では歌詞を左右に、縦画面では上下または左右に配置します。

プレビューの点線は空白の2つの範囲を示し、出力には含まれません。

### 出力形式と範囲

| フォーマット | 使用 |
|---|---|
| MP4 | 完成映像。音源があれば含めることができます。 |
| PNGシーケンスZIP | フレームごとの画像を別のエディタで組み立てるときに使用します。 |
| 透明PNG ZIP | 背景なしで文字と演出を合成するときに使用します。 |
| 前景・後径分離 PNG ZIP | `front/`と `back/` フォルダに1フレームの前後要素を別々に保存します。 |
| LRC | 各行の開始時刻を記録した歌詞ファイルです。 |
| After Effects 用 JSON | 現在のタイミングと設定情報をGULZA AEパネルに移動するときに使用します。 |

**エクスポートする範囲**で最初・終了行を選ぶと選択した行だけ出力します。ファイル名に `_L03-05`のように行番号が付きます。

Chrome・Edgeでは大きな映像を保存するファイルに直接記録できます。GPUエンコーディングに失敗した場合は、別の方法を試してください。

ブラウザがAAC音声を保存できない場合は、別々のWAVファイルが一緒に保存されることがあります。

**歌詞をクリア**は歌詞と並ぶタイミング・指定・出力範囲をクリアします。この操作は元に戻すことができます。

**初期化**保存した音源、設定、作業履歴まで消去します。確認後実行され、元に戻せません。

個別にダウンロードしたプロジェクトのJSONファイルは消去されません。

### フレームレートと動き

出力フレームレートは24/30/60fpsから選択されます。フレームレートと動きの質感は別々の設定です。

- **2フレームホールド：** 毎秒12枚の動きで切れるような感触を作ります。
- **3フレームホールド：** 毎秒8枚でさらに止まった感じを作ります。
- **全体：** 選択した出力fpsごとに移動し、最も滑らかです。

60fpsと4Kは出力に時間がかかります。

### グリーンスクリーン・ブラック背景と透明PNG

別の映像に歌詞を載せるには **エクスポート→背景**からグリーンスクリーン、黒の背景、一般的な背景のいずれかを選びます。

グリーンスクリーンは緑 `#00FF00`、黒の背景は黒 `#000000`を使用します。設定はプレビューと出力の両方に反映されます。

ファイル名に `_greenback` または `_blackback`この付いています。

グリーンスクリーンはクロマキーで、黒の背景はスクリーン合成または明るさキーで削除します。

透明なPNGを選択すると、背景を削除することなく合成できます。前景・後径分離ZIPでは `front/`を `back/` 上に置きます。

フラッシュとスクリーン効果は両方のレイヤーに適用される可能性があるため、合成結果を確認してください。

### 歌詞の言語とフォント

**歌詞の言語**のデフォルトは自動検出です。ハングル・ガーナ・漢字・英語を調べて言語を判別します。

結果が合わない場合は、韓国語、日本語、中国語（繁体字/簡体字）、英語の中から直接選択できます。画面自体は韓国語のままです。

| オリジナルスタイルのフォントファミリー | ハングル歌詞で対応するフォントの例 |
|---|---|
| Noto Sans JP·Zen Kaku Gothic New | Noto Sans KR |
| Noto Serif JP·Zen Old Mincho | Noto Serif KR |
| Dela Gothic One | Black Han Sans |
| M PLUS Rounded 1c | Jua |
| Mochiy Pop One·Kiwi Maru | Do Hyeon·Gowun Dodum |
| Klee One·Yuji Syuku | Gowun Batang·Nanum Brush Script |

英語の歌詞では、いくつかの単語をまとめてカットを分割します。 `/`で直接割った位置があれば、その区分に従います。

言語選択はプロジェクトJSONにも保存されます。

### 初めて使用する方へのご案内

初めてサイトを開くと、歌詞→音源→自動生成→プレビュー→行別編集→書き出し順に案内が出ます。

上の **?** ボタンでもう一度開くことができます。

プレビュー音量とミュート設定はブラウザに保存されます。プレビュー音量は出力MP4の音量を変えません。

## After Effects パネル

GULZA の名前でビルドした ScriptUI と CEP の 2 種類のパネルを提供します。

メニュー名、作成するコンポジション名、診断レポートのファイル名、CEP 拡張 ID も GULZA に合わせています。

ブラウザー版の **AE 用に書き出し**は、各カットの開始・終了時刻を JSON に保存します。

ScriptUI パネルはその時刻を AE レイヤーの開始・終了位置に適用します。

| 種類 | ファイル | 用途 |
|---|---|---|
| ScriptUI | [`GULZA_AE.jsx`](GULZA_AE.jsx) | AE 内で歌詞からコンポジションを作るか、ブラウザー版の構成 JSON を読み込みます。 |
| CEP | [`GULZA_CEP.zip`](GULZA_CEP.zip) | 韓国語のブラウザー編集画面を AE パネル内で使用します。 |

### ScriptUI のインストール

1. `GULZA_AE.jsx` をダウンロードします。
2. AE のインストールフォルダーにある `Scripts/ScriptUI Panels` に入れます。
3. AE を再起動し、**ウィンドウ → GULZA_AE.jsx** から開きます。

歌詞・スタイル・画面サイズ・演出を選んでコンポジションを作成します。

開始時刻は自動計算のほか、選択した音声レイヤーまたはコンポジションのマーカーから指定できます。

ブラウザー版の **AE 用 JSON** を読み込み、同じタイミングと構成でコンポジションを作ることもできます。

作成した歌詞は後で変更できるテキストレイヤーとして残ります。

### CEP のインストール

1. `GULZA_CEP.zip` をダウンロードして展開します。
2. OS に応じて `install_win.bat` または `install_mac.command` を実行します。
3. AE を再起動し、**ウィンドウ → エクステンション → GULZA** から開きます。

CEP は AE 2022 以降を対象とします。拡張 ID（`com.ruruoni1.gulza`）は元の JIZURA パネルとは別です。

インストーラーはユーザーの CEP 拡張フォルダーへパネルをコピーし、署名されていない CEP パネルの実行設定を有効にします。

詳しくは [CEP インストールガイド](cep/dist/README_CEP.md)をご覧ください。

両パネルには軽量生成、進行状況・停止、診断レポートの機能があります。

このリリースの作業環境には After Effects がないため、AE 内での動作は確認できていません。

## 開発と展開

ブラウザ版は、ストレージルートで次のようにビルドします。

```sh
python build.py
```

`src/`, `app/`, `vendor/`からルート `index.html`と `sitemap.xml`を生成します。

GitHub Pagesは `main` ブランチのストレージルートを公開します。 [ベースアドレス](https://ruruoni1.github.io/gulza/ja/)は韓国語の画面です。

日本語・英語・中国語（繁体・簡体）・インドネシア語・ベトナム語 HTMLも各言語フォルダに生成します。

オリジナルのAfter Effects関連のビルドツールもリポジトリにあります。

```sh
node tools/export_ae_data.js
python build_ae.py
python build_cep.py
```

ブラウザ版のバージョンは [`VERSION`](VERSION)、変更履歴は [`CHANGELOG.md`](CHANGELOG.md)に記録します。

表現パーツを追加するには [`docs/EXPRESSION_PACKS.md`](docs/EXPRESSION_PACKS.md)を参照してください。

AE・CEP出力を再作成した場合は、実際のAfter Effectsで別途確認する必要があります。
