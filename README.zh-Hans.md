# GULZA — 动态歌词视频制作工具

GULZA 可以在浏览器中制作动态歌词和字幕视频，并导出 MP4。

此分支可以直接导入 SRT 字幕文件，无需先转换为 LRC。

**[打开简体中文版](https://ruruoni1.github.io/gulza/zh-hans/)** · [仓库首页（韩语）](README.md) · [原版 JIZURA](https://github.com/852wa/JIZURA)

其他语言：[한국어](README.ko.md) · [日本語](README.ja.md) · [English](README.en.md) · [繁體中文](README.zh-Hant.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md)

## 快速开始

1. 导入 SRT 或 LRC 文件，或者逐行输入歌词。
2. 可按需导入音频并调整时间。
3. 生成新的风格和画面布局。
4. 预览后导出 MP4。

导入 SRT 时会保留字幕的开始时间、结束时间和字幕之间的空白。也可以在歌词输入框中修改时间标记。

## 界面和歌词语言

界面语言菜单位于网站顶部。主网址默认显示韩语界面。

**歌词语言**是另一项设置，用于选择字体和文字分段方式，默认自动检测。

还支持手动调整时间、画面比例、PNG 导出、项目 JSON，以及用于 After Effects 的 JSON。

GULZA 基于 [JIZURA](https://github.com/852wa/JIZURA)。源代码采用 [MIT 许可证](LICENSE)。
