# GULZA — 免费动态歌词与字幕视频制作工具

**[使用简体中文网站](https://ruruoni1.github.io/gulza/zh-hans/)** · [韩语原文](README.md) · [原版 JIZURA](https://github.com/852wa/JIZURA)

**其他语言：** [한국어](README.md) · [日本語](README.ja.md) · [English](README.en.md) · [繁體中文](README.zh-Hant.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md)

GULZA 是免费的浏览器工具，可用歌词和字幕制作动态视频并保存为 MP4。

名称来自韩语“글자”（文字）。

本项目基于 [JIZURA](https://github.com/852wa/JIZURA) 的 860 个表现组件和 27 种风格。

这个分支可以直接导入 SRT 字幕文件，无需先转换为 LRC。

**当前版本：v0.14.3** · 无需安装或注册，即可使用[网站](https://ruruoni1.github.io/gulza/zh-hans/)。主网址默认显示韩语界面，可在页面顶部切换语言。

## 这个分支新增的功能

- **直接导入 SRT：** 直接打开 `.srt` 文件制作字幕视频；没有字幕的片段也会保留。
- **韩语字幕文件支持：** 可读取 UTF-8、UTF-16 及韩语 Windows 编码的 SRT/LRC，文件上限为 2 MB。
- **导出 LRC：** 将每条字幕的开始时间保存为 LRC。要保留结束时间，请保存包含 SRT 的项目。
- **切换界面语言：** 默认是韩语，也可以选择日语、英语、繁体与简体中文、印尼语和越南语。
- **GULZA 文件名：** 未填写标题时，使用 `gulza.mp4`、`gulza.project.json` 等默认文件名。

SRT 时间标记会以 `[SRT:00:00:01.000-->00:00:02.300]字幕` 的形式显示在歌词输入框中。

修改标记即可调整字幕时间。

## 主要特点

- **自动配置：** 一键式 `R` 使用按键重新创建风格、情绪、动作、配色方案和剪切构图。如果您更改种子，视频将会有所不同。
- **编辑时间：** 您可以检测音源的节拍并设置剪切，或者在播放过程中直接点击以指定行和剪切的开始时间。
- **输出设置：** 选择 16:9、9:16、4:3、3:4、1:1、4:5、21:9 宽高比、720p~4K 分辨率、24/30/60fps。
- **视频和图片：** 您可以导出 MP4、PNG 序列、透明 PNG 和前景/背景分离的 PNG。您还可以在绿屏和黑色背景之间进行选择。
- **保存项目：** 您可以将编辑保存为 JSON 并重新打开，甚至可以导出 After Effects 的配置 JSON。

## 入门

1. [古尔扎网站](https://ruruoni1.github.io/gulza/zh-hans/)打开 。
2. **加载SRT/LRC**用 选择字幕文件，或直接在歌词输入栏中逐行写入。
3. 如果有声源，则加载它。即使没有音频源，您也可以创建带字幕的视频。
4. **自动创建**点击并检查预览。我喜欢的是 **上一页/下一页**您可以再次选择它。
5. 设置好屏幕比例、分辨率、帧率后， **导出MP4**按 。

### 使用环境

MP4 导出需要浏览器中的 WebCodecs 支持。推荐使用 Chrome 和 Edge。

可用的编解码器因您的浏览器和操作系统而异。即使您无法创建 MP4，您仍然可以预览和导出 PNG 序列。

您也可以在智能手机上对其进行编辑。 PC 更适合长视频或高分辨率输出。

所需的字体是从 Google Fonts 加载的。离线时，设备上的字体可能会回退。

## 自动创建和微调

屏幕的 **简单/高级**更改 中的编辑模式。

在简单模式下 **自动创建**按一次可重新选择以下全部内容。

- 标题和正文中使用的样式、背景颜色和字体
- 情绪：小故障、寒冷、流行、图形、社论、情感，综合混合。如果你开启恐怖导演，恐怖也会被纳入候选范围。
- 动作的强度、故障和装饰的数量以及要使用的表现力部件。
- 剪切配置和种子

**上一页/下一页**您可以在使用 创建的记录之间来回切换。

**只需更改这部分即可**保持当前设计并仅选择以下其中一项：风格、配色方案、氛围和构图。

歌词、声源、时间、输出设置和锁定行都是自动创建的，不会更改。

### 手机屏幕

当屏幕较窄或使用触摸操作时 **移动的** 模式可用。

即使滚动时，自动生成的按钮和预览也是可见的。通过仅展开您需要的行来编辑行列表。

保存、打开、重置都集中在菜单中。移动模式下的第一个输出分辨率是720p。

### 更改配色方案

**高级 → 样式 → 强调色/偏移色**在 **随机配色方案**按 重新选择两种颜色。

您可以从现成的组合或色轮创建新的组合。还可以调整颜色的亮度，以便根据背景亮度来读取文本。

您也可以自己指定颜色。如果清除指定的颜色，它将返回到样式的默认颜色。

## 浏览器编辑详细说明

### 歌词和字幕符号

通常，一行歌词就是一个短语。

空白行会产生短暂的间隙。

| 输入示例 | 意义 |
|---|---|
| `새벽의 색을/기억하고 있어` | `/`将切口分开。 |
| `*투명*` | 强调这个词。 |
| `마지막 문장!` | 在行尾添加闪光和摆动。 |
| `가사\|작은 메모` | 添加小文本以供评论。 |
| `[01:23.45]가사` | 应用 LRC 开始时间。 |
| `[간주 8]` | 它只显示了8秒的背景和装饰，没有任何歌词。如果没有数字，则为 4 秒。 |
| `# 메모` | 这将被视为作品注释，不会包含在视频中。 |

**加载SRT/LRC**如果使用 打开文件，当前歌词将会更改。更改之前将打开一个确认窗口。

即使在打电话之后 **恢复**您可以使用 恢复之前的状态。

SRT 维护开始和结束时间。 LRC 只能包含开始时间。

### 声源及时序

- 当您加载声源时，它会检测 BPM 和节拍，并将剪切边界调整为更接近节拍。加载的音乐将保留在同一浏览器中，并且可以在您重新打开页面时恢复。
- **与选项卡同步：** 当每一行开始时 `Space`按 。如果您按错了按钮 `Backspace`我 **恢复一**使用 。
- **再次从中间开始：** 按线路列表中的同步按钮。
- **选项卡辅助功能：** 您可以将播放速度降低至 0.75 倍或 0.5 倍，或者打开倒计时。保存时间是歌曲的原始时间。
- **剪切时间：** 当一条线路有多个剪切时，切换时 `Tab`按 。
- 您可以直接以数字形式输入行列表的开始时间，也可以通过拖动时间线的行边框来调整它。您还可以放大/缩小时间线并移动播放位置。
- 歌词和时间变更 **恢复** 或者 `Ctrl+Z`您可以使用 取消。

### 分别编辑线条和剪切

您可以通过按行列表中的铅笔按钮或双击歌词来编辑该行。

每条线的切割次数可以设置为自动或 1 到 6。您也可以用骰子再次绘制该线。

打开后，锁会保持其线条的组成和配色方案。 **随机播放**重新拉动整个配置而不锁定它。

**主题**如果选择文字视频、动感、日式、恐怖、流行、民谣之一，自动生成方向将缩小。

在高级模式下，您可以更改每个剪辑的布局、外观、维护、退出、装饰、文本效果、背景、相机和过渡。

即使在自动创建后，分类锁和表示值锁仍会保留，并保存在项目文件中。

下次去玩 **重复**按以下顺序更改：全部→行→剪切→无重复。

重复范围显示在时间线上。

### 风格、方向、字体

27 种样式是结合了颜色组合、字体和纹理的设置。

有樱花、深海、日落、报纸、纸张、合成器和恐怖风格。即使在一个视频中，每次剪辑的背景也可能会发生变化。

需要时加载字体。您的 PC 上安装的字体名称 `.ttf`·`.otf` 您也可以将其更改为文件。

**高级 → 方向**调整运动、故障、颜色错位、装饰、切割密度、纹理和框架保持。

即使你隐藏了装饰性的数字和时间，歌词中写的数字本身也会保留下来。

**高级 → 技术**您可以单独打开和关闭 10 类表现组件。它还提供名称搜索和完整的开/关/反转。

**团结感**打开后，单独的部分和重复的歌词使用相似的布局和动作。在需要强调的线条上放置强有力的方向。

**字符对齐**调整字体大小、间距和装饰。这两个选项都可以关闭。

**空中心（用于字符）**确保中心空间以合成其他图像。

歌词在横屏上左右放置，在竖屏上上下或左右放置。

预览中的虚线显示将留空且不会包含在输出中的范围。

### 帧速率和运动

从 24/30/60fps 中选择输出帧速率。帧速率和运动纹理是单独的设置。

- **2 帧保持：** 每秒 12 张图片的移动会产生一种断开的感觉。
- **3帧保持：** 每秒 8 次射击营造出更加冰冻的感觉。
- **全部的：** 它以每个选定的输出 fps 移动，以获得最流畅的体验。

60fps 和 4K 需要更长的时间才能输出。

### 绿屏、黑色背景和透明PNG

将歌词放在另一个视频之上 **导出 → 背景**在绿屏、黑色背景或纯背景之间进行选择。

绿屏是绿色的 `#00FF00`，黑色背景为黑色 `#000000`使用 。设置会反映在预览和输出中。

在文件名中 `_greenback` 或者 `_blackback`这是附上的。

使用色度键去除绿屏，使用屏幕合成或亮度键去除黑色背景。

如果选择透明PNG，则可以在不删除背景的情况下进行合成。在前景和背景分离的ZIP中， `front/`投掷 `back/` 将其放在上面。

Flash 和屏幕效果可以应用在两层中，因此请检查合成结果。

## After Effects 面板

提供以 GULZA 名称构建的 ScriptUI 和 CEP 两种面板。

菜单、生成的合成、诊断报告文件名和 CEP 扩展 ID 都使用 GULZA 名称。

浏览器版的 **导出至 AE** 会将每个剪辑的开始和结束时间写入 JSON。

ScriptUI 面板会把这些时间应用于 AE 图层的起点和终点。

| 类型 | 文件 | 用途 |
|---|---|---|
| ScriptUI | [`GULZA_AE.jsx`](GULZA_AE.jsx) | 在 AE 中用歌词创建合成，或读取浏览器版的配置 JSON。 |
| CEP | [`GULZA_CEP.zip`](GULZA_CEP.zip) | 在 AE 面板中使用韩语浏览器编辑界面。 |

### 安装 ScriptUI

1. 下载 `GULZA_AE.jsx`。
2. 将文件放入 AE 安装目录下的 `Scripts/ScriptUI Panels`。
3. 重新启动 AE，从 **窗口 → GULZA_AE.jsx** 打开。

选择歌词、风格、画面大小和效果后创建合成。

开始时间可以自动计算，或使用所选音频图层及合成的标记。

也可以读取浏览器版保存的 **AE 用 JSON**，以相同时间和配置创建合成。

生成的歌词仍是可编辑的文本图层。

### 安装 CEP

1. 下载并解压 `GULZA_CEP.zip`。
2. 按操作系统运行 `install_win.bat` 或 `install_mac.command`。
3. 重新启动 AE，从 **窗口 → 扩展功能 → GULZA** 打开。

CEP 适用于 AE 2022 或更新版本。扩展 ID（`com.ruruoni1.gulza`）与原版 JIZURA 面板不同。

安装程序会将面板复制到用户 CEP 扩展目录，并启用未签名 CEP 面板的运行设置。

详见 [CEP 安装说明](cep/dist/README_CEP.md)。

两种面板均提供轻量生成、进度与停止控制，以及诊断报告。

本次发布所用电脑未安装 After Effects，因此尚未确认面板在 AE 中的实际运行情况。
