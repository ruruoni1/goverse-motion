# GOVERSE Motion — 무료 모션 자막 제작기

**[웹사이트에서 바로 사용하기](https://ruruoni1.github.io/goverse-motion/)** · [빠른 사용 안내](README.ko.md) · [원본 JIZURA](https://github.com/852wa/JIZURA)

GOVERSE Motion은 가사나 자막을 넣으면 문자 중심의 모션 영상을 자동으로 구성하고 MP4로 내보내는 브라우저 도구입니다. [JIZURA](https://github.com/852wa/JIZURA)의 **860개 표현 부품과 27개 스타일**을 바탕으로 하며, 이 포크에는 **SRT 자막을 파일 그대로 불러와 시작·종료 시각과 자막 사이의 공백을 유지하는 기능**을 더했습니다. 공개 웹사이트는 한국어 화면 한 가지만 제공합니다.

현재 버전은 **v0.11.3**입니다. 설치나 회원가입 없이 사이트에서 바로 작업할 수 있습니다.

## 이 포크에서 추가한 기능

| 기능 | 설명 |
|---|---|
| SRT 직접 불러오기 | `.srt` 파일을 선택하면 각 자막의 시작·종료 시각을 편집기에 보존합니다. 자막이 없는 구간도 영상에 반영합니다. |
| 한국어 자막 파일 읽기 | UTF-8, UTF-16, 한국어 Windows 인코딩으로 저장된 SRT/LRC 파일을 읽습니다. 파일 크기 제한은 2 MB입니다. |
| SRT에서 LRC로 변환 | **LRC 내보내기**로 각 자막의 시작 시각을 담은 파일을 저장할 수 있습니다. LRC에는 종료 시각이 없으므로 원래 시간 구간을 모두 유지하려면 SRT가 포함된 프로젝트를 사용하세요. |
| 한국어 웹사이트 | 편집기, 안내 문구, 언어 선택 항목과 저장소 첫 화면을 한국어로 구성했습니다. |
| 저장 파일 이름 | 제목을 입력하지 않으면 `goverse-motion.mp4`, `goverse-motion.project.json`처럼 제품 이름을 기본 파일명으로 사용합니다. |

SRT 자막은 편집란에서 `[SRT:00:00:01.000-->00:00:02.300]자막` 형태로 표시됩니다. 시간 표식을 수정하면 해당 자막의 시간도 바뀝니다. **SRT 추가 기능은 브라우저판에 구현되어 있습니다.** 저장소에 포함된 After Effects 패널 파일은 원본 JIZURA에서 이어받은 것이며, SRT의 종료 시각을 패널에서 동일하게 처리하는지는 별도로 확인해야 합니다.

## 주요 기능

- **자동 구성:** 버튼 한 번이나 `R` 키로 스타일, 분위기, 움직임, 배색, 컷 구성을 다시 만듭니다. 같은 설정이라도 시드를 바꾸면 다른 영상이 됩니다.
- **타이밍 편집:** 음원의 박자를 감지해 컷을 맞추거나, 재생하면서 직접 탭해 줄과 컷의 시작 시각을 지정할 수 있습니다.
- **출력 설정:** 16:9, 9:16, 4:3, 3:4, 1:1, 4:5, 21:9 화면비와 720p~4K 해상도, 24/30/60fps를 선택합니다.
- **영상과 이미지:** MP4, PNG 시퀀스, 투명 PNG, 전경·후경 분리 PNG를 내보낼 수 있습니다. 그린 스크린과 블랙 배경도 선택할 수 있습니다.
- **프로젝트 저장:** 편집 내용을 JSON으로 저장했다가 다시 열 수 있고, After Effects용 구성 JSON도 내보낼 수 있습니다.

| 저장소의 파일 | 용도 |
|---|---|
| [`index.html`](index.html) | GitHub Pages가 제공하는 한국어 브라우저판. 단일 HTML 파일입니다. |
| [`src/`](src/) · [`app/`](app/) | 모션 엔진, 화면, 한국어 번역과 빌드 소스 |
| [`JIZURA_AE.jsx`](JIZURA_AE.jsx) | 원본에서 이어받은 After Effects ScriptUI 패널 |
| [`JIZURA_CEP.zip`](JIZURA_CEP.zip) | 원본에서 이어받은 After Effects CEP 패널 |
| [`ae/`](ae/) · [`cep/`](cep/) | After Effects 패널의 소스와 설치 자료 |
| [`docs/EXPRESSION_PACKS.md`](docs/EXPRESSION_PACKS.md) | 표현 부품을 추가하는 개발자를 위한 문서 |

## 시작하기

1. [GOVERSE Motion 사이트](https://ruruoni1.github.io/goverse-motion/)를 엽니다.
2. **SRT/LRC 불러오기**로 자막 파일을 선택하거나, 가사 입력란에 한 줄씩 직접 적습니다.
3. 음원이 있다면 불러옵니다. 음원이 없어도 자막 영상은 만들 수 있습니다.
4. **자동으로 만들기**를 누르고 미리보기를 확인합니다. 마음에 드는 안은 **이전 / 다음**으로 다시 선택할 수 있습니다.
5. 화면비·해상도·프레임레이트를 정한 뒤 **MP4 내보내기**를 누릅니다.

### 사용 환경

MP4 내보내기에는 브라우저의 WebCodecs 지원이 필요합니다. Chrome과 Edge를 권장합니다. 인코딩 가능한 코덱은 브라우저와 운영체제에 따라 달라집니다. MP4를 만들 수 없는 환경에서도 미리보기와 PNG 시퀀스 내보내기를 사용할 수 있습니다.

스마트폰에서도 편집할 수 있습니다. 긴 영상이나 높은 해상도를 내보낼 때는 PC가 더 적합합니다. 글꼴은 현재 구성에 필요한 것만 Google Fonts에서 불러오며, 오프라인에서는 기기에 있는 글꼴로 대체될 수 있습니다.

## 자동 생성과 세부 조정

화면의 **간단 / 고급**에서 편집 모드를 바꿉니다. 간단 모드에서 **자동으로 만들기**를 누르면 다음을 한꺼번에 다시 고릅니다.

- 스타일과 배경색, 제목·본문에 쓰는 글꼴
- 분위기: 글리치, 차분함, 팝, 그래픽, 에디토리얼, 감성, 전체 혼합. 호러 연출을 켜면 호러도 후보에 들어갑니다.
- 움직임의 강도, 글리치와 장식의 양, 사용할 표현 부품
- 컷 구성과 시드

**이전 / 다음**으로 생성한 안의 기록을 오갈 수 있습니다. **이 부분만 변경**에서는 현재 안을 유지한 채 스타일, 배색, 분위기, 구성 중 하나만 다시 뽑습니다. 가사·음원·타이밍·출력 설정과 잠근 줄은 자동 생성으로 바뀌지 않습니다.

### 자동 생성에 사용할 표현 범위

체크 항목으로 자동 생성·셔플·줄별 재추첨의 후보를 제한할 수 있습니다. 직접 선택한 표현은 이 제한과 관계없이 사용할 수 있습니다.

| 항목 | 처음 상태 | 작동 방식 |
|---|---|---|
| 추가 연출도 사용 | 꺼짐 | 켜면 초기 공개판의 356개 부품과 12개 스타일에 추가된 표현과 스타일, 글꼴도 후보에 포함합니다. |
| 일본풍 연출도 사용 | 켜짐 | 초롱·쇼지·부채·벚꽃·전통 무늬 등 일본풍 표현을 후보에 포함합니다. |
| 타이포그래피 부품 사용 | 켜짐 | 선, 숫자, 자간, 글자 조판으로 표현하는 문자 영상용 부품 50개를 사용합니다. |
| 키네틱 부품 사용 | 켜짐 | 단어가 움직이고 쌓이거나 교차하는 부품 51개를 사용합니다. |
| 호러 연출도 사용 | 꺼짐 | 호러 부품 52개와 관련 스타일 3개를 사용하고 자동 생성 분위기에 호러를 추가합니다. |

표현 목록에서는 추가분·일본풍·타이포그래피·키네틱·호러 부품에 각각 표시가 붙습니다. 현재 설정에서 자동 선택되지 않는 항목은 흐리게 보입니다.

### 모바일 화면

화면이 좁거나 터치로 조작할 때는 **모바일 / 간단 / 고급** 중 모바일 모드를 사용할 수 있습니다. 자동 생성 버튼과 미리보기가 화면을 스크롤해도 보이도록 배치되고, 줄 목록은 필요한 줄만 펼쳐 편집합니다. 저장·열기·초기화는 메뉴에 모입니다. 모바일 모드의 첫 출력 해상도는 720p로 설정됩니다.

### 배색 바꾸기

**고급 → 스타일 → 강조색·오프셋 색**에서 **랜덤 배색**을 누르면 강조색과 색 어긋남에 쓰는 두 색을 다시 고릅니다. 준비된 조합을 사용하거나 색상환에서 새 조합을 만들며, 배경 밝기에 맞춰 글자가 읽히도록 색의 밝기를 조정합니다. 색을 직접 지정할 수도 있습니다. 직접 지정한 색을 해제하면 선택한 스타일의 기본 색으로 돌아갑니다.

## 브라우저 편집 상세 안내

### 가사와 자막 표기

보통 가사 한 줄이 한 프레이즈입니다. 빈 줄은 잠깐의 간격을 만듭니다.

| 입력 예시 | 의미 |
|---|---|
| `새벽의 색을/기억하고 있어` | `/`에서 컷을 나눕니다. |
| `*투명*` | 해당 단어를 강조합니다. |
| `마지막 문장!` | 줄 끝에 플래시와 흔들림을 넣습니다. |
| `가사|작은 메모` | 주석용 작은 글자를 덧붙입니다. |
| `[01:23.45]가사` | LRC 시작 시각을 적용합니다. |
| `[간주 8]` | 8초 동안 가사 없이 배경과 장식만 보여 줍니다. 숫자가 없으면 4초입니다. |
| `# 메모` | 작업용 주석으로 처리해 영상에는 넣지 않습니다. |

**SRT/LRC 불러오기**로 파일을 열면 현재 가사가 바뀝니다. 바꾸기 전에 확인창이 열리며, 불러온 뒤에도 **되돌리기**로 직전 상태를 복구할 수 있습니다. SRT의 각 문장은 시작·종료 시각을 함께 유지합니다. LRC에는 시작 시각만 있으므로 종료 시각을 담을 수 없습니다.

### 음원과 타이밍

- 음원을 불러오면 BPM과 박자를 감지해 컷 경계를 박자에 가깝게 맞춥니다. 불러온 음원은 같은 브라우저에 보관되어 페이지를 다시 열 때 복구될 수 있습니다.
- **탭으로 동기화**에서 곡을 들으며 각 줄의 시작에 `Space`를 누릅니다. 잘못 눌렀다면 `Backspace`나 **하나 되돌리기**를 사용합니다. 줄 목록의 동기화 버튼으로 중간 줄부터 다시 시작할 수도 있습니다.
- 탭하는 동안 재생 속도를 0.75배 또는 0.5배로 낮추거나 카운트다운을 켤 수 있습니다. 저장되는 시각은 곡의 원래 시간입니다. 한 줄에 컷이 여러 개면 컷 전환 시 `Tab`을 눌러 컷 시작도 맞춥니다.
- 줄 목록의 시작 시각을 숫자로 직접 입력하거나 타임라인의 줄 경계를 드래그해 조정할 수 있습니다. 타임라인 확대·축소와 재생 위치 이동도 가능합니다.
- 가사·타이밍 변경은 **되돌리기** 또는 `Ctrl+Z`로 취소할 수 있습니다.

### 줄과 컷을 따로 편집하기

줄 목록에서 연필 버튼을 누르거나 가사를 두 번 클릭하면 해당 줄만 수정할 수 있습니다. 줄마다 컷 수를 자동 또는 1~6개로 지정하고, 주사위로 그 줄만 다시 뽑을 수 있습니다. 자물쇠를 켜면 그 줄의 구성과 배색을 유지합니다. **셔플**은 잠그지 않은 전체 구성을 다시 뽑습니다.

**테마**에서 문자 영상, 키네틱, 일본풍, 호러, 팝, 발라드 중 하나를 선택하면 자동 생성 방향이 그 테마로 좁혀집니다. 고급 모드에서는 프리뷰의 컷 정보에서 레이아웃·등장·유지·퇴장·장식·글자 효과·배경·카메라·전환을 컷마다 바꿀 수 있습니다. 분류별 잠금과 연출 값 잠금은 자동 생성을 다시 눌러도 선택을 유지하며 프로젝트 파일에도 저장됩니다.

재생 옆의 **반복**은 전체 → 줄 → 컷 → 반복 없음 순서로 바뀝니다. 반복 범위는 타임라인에 표시됩니다.

### 스타일, 연출, 글꼴

27개 스타일은 배색·서체·질감을 묶은 설정입니다. 사쿠라, 심해, 석양, 신문, 종이, 신스 계열과 호러용 스타일 등이 있으며, 한 영상 안에서도 컷에 따라 배경이 바뀔 수 있습니다. 사용 중인 글꼴만 필요할 때 불러옵니다. PC에 설치된 글꼴 이름을 입력하거나 `.ttf`·`.otf` 파일을 불러와 바꿀 수도 있습니다.

**고급 → 연출**에서 움직임, 글리치, 색 어긋남, 장식, 컷 밀도, 질감, 프레임 홀드를 조정합니다. 장식용 번호와 시각을 숨기는 옵션은 가사 자체에 적힌 숫자는 지우지 않습니다. **고급 → 기법**에서는 레이아웃·등장·유지·퇴장·장식·글자 효과·배경·카메라·화면 효과·전환의 10개 분류를 펼쳐 개별 부품을 켜고 끌 수 있습니다. 이름 검색과 전체 켜기·끄기·반전도 제공합니다.

**통일감**을 켜면 빈 줄로 구분된 파트와 반복되는 가사에서 비슷한 레이아웃과 움직임을 사용하고, 강조할 줄에 강한 연출을 배치합니다. **문자 정렬**은 가독성을 위해 글자 크기·간격·장식을 조정하는 옵션입니다. 두 옵션 모두 끌 수 있습니다.

**가운데 비우기(캐릭터용)**는 캐릭터나 다른 영상을 중앙에 합성할 공간을 확보합니다. 가로 화면에서는 가사를 좌우에, 세로 화면에서는 위아래 또는 좌우에 배치합니다. 미리보기에는 비워 둘 범위를 점선으로 보여 주지만 점선은 출력물에 포함되지 않습니다.

### 출력 형식과 범위

| 형식 | 쓰임 |
|---|---|
| MP4 | 완성 영상. 음원이 있으면 포함할 수 있습니다. |
| PNG 시퀀스 ZIP | 프레임별 이미지를 다른 편집기에서 조립할 때 사용합니다. |
| 투명 PNG ZIP | 배경 없이 글자와 연출을 합성할 때 사용합니다. |
| 전경·후경 분리 PNG ZIP | `front/`와 `back/` 폴더에 한 프레임의 앞뒤 요소를 따로 저장합니다. |
| LRC | 각 줄의 시작 시각을 기록한 가사 파일입니다. |
| After Effects용 JSON | 현재 타이밍과 구성 정보를 원본 AE 패널로 옮길 때 사용합니다. |

**내보낼 범위**에서 처음·끝 줄을 고르거나 줄 목록에서 범위를 지정하면 선택한 줄만 출력합니다. 파일명에 `_L03-05`처럼 줄 번호가 붙습니다. Chrome·Edge에서는 큰 영상을 위해 저장할 파일을 먼저 고르고 직접 기록하는 기능도 사용할 수 있습니다. GPU 인코딩이 실패하면 다른 인코딩 방법을 시도합니다. 브라우저에서 AAC 음성으로 저장하지 못하는 경우에는 별도의 WAV 파일이 함께 저장될 수 있습니다.

**가사 지우기**는 가사와 줄별 타이밍·지정·출력 범위를 지우며 되돌릴 수 있습니다. **초기화**는 저장된 음원, 설정과 작업 기록까지 지우므로 확인 후 실행하며 되돌릴 수 없습니다. 별도로 내려받은 프로젝트 JSON 파일은 지워지지 않습니다.

### 프레임레이트와 움직임

출력 프레임레이트는 24/30/60fps 중에서 고릅니다. 영상의 프레임 수와 움직임의 질감은 별도입니다. **2프레임 홀드**는 초당 12장의 움직임으로 문자 영상 특유의 끊기는 느낌을 만들고, **3프레임 홀드**는 초당 8장으로 더 멈춘 느낌을 만듭니다. **전체**는 선택한 출력 fps마다 움직여 가장 매끄럽습니다. 60fps와 4K는 출력 시간이 더 걸립니다.

### 그린 스크린·블랙 배경과 투명 PNG

다른 영상 위에 가사만 얹으려면 **내보내기 → 배경**에서 그린 스크린, 블랙 배경, 일반 배경 중 하나를 고릅니다. 그린 스크린은 초록색 `#00FF00`, 블랙 배경은 검은색 `#000000` 위에 흰 글자와 연출을 놓습니다. 미리보기와 출력 모두에 반영되며 파일명에는 `_greenback` 또는 `_blackback`이 붙습니다.

그린 스크린은 편집기의 크로마키로 초록색을 제거합니다. 블랙 배경은 스크린 합성이나 밝기 키로 검은색을 제거합니다. 투명 PNG를 선택하면 배경을 빼는 단계 없이 합성할 수 있습니다. 전경·후경 분리 ZIP에서는 `front/`를 `back/` 위에 놓으면 됩니다. 플래시와 화면 효과는 두 층에 적용될 수 있으므로 합성 결과를 확인하세요.

### 가사 언어와 글꼴

**가사 언어**의 기본값은 자동 감지입니다. 한글·가나·한자·영문을 살펴 한국어, 일본어, 중국어(번체/간체), 영어를 판별합니다. 결과가 맞지 않으면 직접 고를 수 있습니다. 화면 자체는 한국어로 유지됩니다.

| 원본 스타일의 글꼴 계열 | 한글 가사에서 대응하는 글꼴 예 |
|---|---|
| Noto Sans JP·Zen Kaku Gothic New | Noto Sans KR |
| Noto Serif JP·Zen Old Mincho | Noto Serif KR |
| Dela Gothic One | Black Han Sans |
| M PLUS Rounded 1c | Jua |
| Mochiy Pop One·Kiwi Maru | Do Hyeon·Gowun Dodum |

영어 가사에서는 단어를 몇 개씩 묶어 컷을 나눕니다. `/`로 직접 나눈 위치가 있으면 그 구분을 따릅니다. 언어 선택은 프로젝트 JSON에도 저장됩니다.

### 처음 사용하는 사람을 위한 안내

처음 사이트를 열면 가사 → 음원 → 자동 생성 → 미리보기 → 줄별 수정 → 내보내기 순서의 화면 안내가 나옵니다. 상단의 **?** 버튼으로 다시 열 수 있습니다. 미리보기 음량 슬라이더와 음소거 버튼의 설정은 브라우저에 기억되지만, 미리보기 음량은 출력 MP4의 음량을 바꾸지 않습니다.

## After Effects 패널

저장소에는 원본 JIZURA의 두 패널이 함께 들어 있습니다. **브라우저판에서 새로 추가한 SRT 불러오기와 종료 시각 처리까지 AE 패널에서 동일하게 동작한다고 단정하지 않습니다.** AE로 작업할 때는 브라우저에서 **AE용 내보내기**로 만든 JSON과 실제 컴포지션의 타이밍을 확인하세요.

| 종류 | 파일 | 용도 |
|---|---|---|
| ScriptUI | [`JIZURA_AE.jsx`](JIZURA_AE.jsx) | AE 안에서 가사로 컴포지션을 만들거나 브라우저판의 구성 JSON을 읽습니다. |
| CEP | [`JIZURA_CEP.zip`](JIZURA_CEP.zip) | 브라우저판과 비슷한 편집 화면을 AE 패널 안에서 사용합니다. |

### 설치와 사용

ScriptUI 패널은 `JIZURA_AE.jsx`를 After Effects의 `Scripts/ScriptUI Panels` 폴더에 넣고 AE를 다시 시작한 뒤 **창 → JIZURA_AE.jsx**에서 엽니다. Windows에서는 보통 `C:\Program Files\Adobe\Adobe After Effects <버전>\Support Files\Scripts\ScriptUI Panels\`, macOS에서는 `/Applications/Adobe After Effects <버전>/Scripts/ScriptUI Panels/` 아래에 있습니다. 시험 삼아 실행할 때는 AE의 스크립트 파일 실행 메뉴를 사용할 수도 있습니다.

가사·스타일·화면 크기·연출을 고르고 컴포지션을 만듭니다. 시작 시각은 자동 계산, 선택한 오디오 레이어의 마커, 컴포지션 마커 중에서 정할 수 있습니다. 자동 생성은 스타일·분위기·색·시드를 바꿉니다. 브라우저판의 **AE용 내보내기** JSON을 읽으면 그 구성으로 컴포지션을 만듭니다. 원본 설명에 따르면 가사는 텍스트 레이어로 남아 나중에 교체할 수 있습니다.

CEP 파일은 압축을 푼 뒤 포함된 설치 스크립트와 [`cep/dist/README_CEP.md`](cep/dist/README_CEP.md)의 안내를 따릅니다. AE 2022 이상에서 **창 → 확장 기능 → JIZURA 字面**로 엽니다. 선택한 줄만 컴포지션으로 만들거나, AE에서 선택한 음원과 마커를 사용할 수 있습니다.

원본 패널은 색 어긋남 복제·입자 등을 줄이는 가벼운 생성 모드, 긴 곡 생성 진행률과 중지 기능, 오류·대체 부품 진단 보고서를 제공합니다. AE 2020 이상에서는 JavaScript 표현식 엔진을 전제로 합니다. 원본 문서는 실제 AE 기기에서 모든 경우를 확인한 것은 아니라고 밝히므로, 중요한 작업에서는 작은 프로젝트로 먼저 결과를 확인하세요.

## 개발과 배포

한국어 브라우저판은 저장소 루트에서 다음처럼 빌드합니다.

```sh
python build.py
```

`src/`, `app/`, `vendor/`에서 루트의 `index.html`과 `sitemap.xml`을 생성합니다. GitHub Pages는 `main` 브랜치의 저장소 루트를 게시하며, [공개 주소](https://ruruoni1.github.io/goverse-motion/)에서 한국어판을 열 수 있습니다. 원본의 다른 언어 번역 모듈은 소스에 남아 있지만 별도 언어판 HTML은 빌드하거나 게시하지 않습니다.

원본의 After Effects 관련 빌드 도구도 저장소에 있습니다.

```sh
node tools/export_ae_data.js
python build_ae.py
python build_cep.py
```

브라우저판의 버전은 [`VERSION`](VERSION)에 기록하며 변경 이력은 [`CHANGELOG.md`](CHANGELOG.md)에 남깁니다. 표현 부품을 추가하려면 [`docs/EXPRESSION_PACKS.md`](docs/EXPRESSION_PACKS.md)를 참고하세요. AE·CEP 출력물을 다시 만들었다면 실제 After Effects에서 별도로 확인해야 합니다.
